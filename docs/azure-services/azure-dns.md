# Azure DNS — not yet implemented

Optional, listed in the roadmap's services table but not tied to a specific numbered phase (see [`docs/ROADMAP.md`](../ROADMAP.md)).

**What it will be**: a public DNS zone giving the platform a real hostname (e.g. `shop.example.com`) pointed at Application Gateway's public IP, instead of accessing it by raw IP.

**Why it's optional here**: it's a nice-to-have for demo purposes (a real URL is more presentable than an IP), not something the architecture functionally depends on — Application Gateway works identically either way.

This file will be filled in if/when this is built.
